# Decisions

1. **Standard-library Python + native web client.** This makes the prototype one-command, offline-capable, inspectable, and inexpensive to operate. The API boundary still permits a future optimization service or React client.
2. **Full-scale aggregate generator, request-level clearing kernel.** Five hundred thousand fans are generated reproducibly without a million browser objects. The exact same policy kernel is exercised against representative and test request pools.
3. **Explainable hybrid allocation.** Hard feasibility constraints run before a weighted cohort score and cryptographic seeded tie-break. No arrival field appears in scoring. This is easier to audit than a black-box optimizer; integer programming is a later option for cross-zone global optimality.
4. **Rights-owner catalog is authoritative.** Negotiation reads prices from catalog objects and can expand selection only through explicit acceptance. Pricing and priority are separate.
5. **Block adjacency proxy.** Groups must fit within one 20-seat inventory block. This demonstrates fragmentation constraints without pretending to model a real venue.
6. **Preview before commit.** Supply and second-show interventions first present labeled before/after modeled effects. Demo actions remain in memory so reset is instant.
7. **No LLM dependency.** A deterministic natural-language adapter makes structured alternatives; its interface can later be replaced while authorization stays enforced in code.
